## Gamma-documented presentation experience

- Gamma's help guide says the Present menu offers **Full screen** and **In tab** modes. It documents Left/Right Arrow for slide navigation, Up/Down for scrolling longer slides, and trackpad gestures to preview adjacent slides. A thin bottom progress bar shows position; Exit or Esc leaves Present Mode. [Presenting guide](https://help.gamma.app/en/articles/8032935-what-s-the-best-way-to-present-my-gamma)
- The same guide documents interactive toggles and nested slides (navigate to an element with Up/Down, open or close it with Enter), quick edits while presenting (right-click or `E`), and Spotlight (toolbar or `S`; clicking a content block can spotlight it). Spotlight dims viewed content and fades upcoming content. [Presenting guide](https://help.gamma.app/en/articles/8032935-what-s-the-best-way-to-present-my-gamma) [Spotlight guide](https://help.gamma.app/en/articles/11047295-how-does-spotlight-mode-work-in-gamma)
- Presenter View is a separate documented option from the Present dropdown. It shows the presenter the current slide and private speaker notes, supports arrow-key navigation and live note edits, and includes a presentation timer and shortcut reference. Gamma says notes are not shown to public viewers. [Speaker-notes guide](https://help.gamma.app/en/articles/11047307-can-i-use-speaker-notes-while-presenting-in-gamma)
- Gamma documents a **follow link** flow: the presenter shares it and viewers can click the presenter's avatar to follow the presentation. [Presenting guide](https://help.gamma.app/en/articles/8032935-what-s-the-best-way-to-present-my-gamma)
- **Observed in the current Present view:** The selected card extends below the initial viewport, a vertical scrollbar is visible at the right edge, and the deck progress strip remains along the bottom. This confirms that this presentation allows vertical scrolling within a long slide/card; Gamma's guide also documents scrolling longer slides with Up/Down. [Current deck view](https://gamma.app/docs/AI-Augmented-Programming-k7ti0ycoqkndaq0?mode=present#card-jfv649h2qc6mzvk) [Presenting guide](https://help.gamma.app/en/articles/8032935-what-s-the-best-way-to-present-my-gamma)

## PPTX export and fidelity

Gamma documents PDF, PNG, and PowerPoint (PPTX) export, and explicitly says exported content follows **Present Mode rather than Edit Mode**. PPTX tables can be editable, but PowerPoint does not preserve rounded table corners; speaker notes are included in PPTX; and Gamma embeds theme fonts, though rare embedding failures or apps that ignore embedded fonts can cause substitutions. Gamma also lists gradients and some advanced visual effects as potential export differences, while static PDF export does not retain interactive elements. [Export guide](https://help.gamma.app/en/articles/8022861-what-s-the-easiest-way-to-export-my-gamma) [Export differences](https://help.gamma.app/en/articles/15939201-why-doesn-t-my-exported-pdf-or-powerpoint-match-what-i-see-in-gamma)

## Theme system

- **Visible in the user-provided screenshot:** A Theme side panel includes a New theme action, text stating that themes customize colors, fonts, logo, and other visual styling, category chips labeled Dark, Light, Professional, and Colorful, theme previews with one selected, and per-theme overflow menus. This establishes what that screenshot shows, not what each control does or how a theme is stored.
- **Documented by Gamma:** Gamma defines a theme as the visual style of content, including colors, fonts, slide styles, and accent images. Its customization guide also documents controls for background and palette colors, typography, logos, design elements such as roundness/strokes/shadows, and image styling. The dashboard guide places theme management under Customize and distinguishes a theme (appearance) from a template (prebuilt content and layout). [Customize themes, colors, and fonts](https://help.gamma.app/en/articles/11029150-how-do-i-customize-themes-colors-and-fonts-in-gamma) [Dashboard guide](https://help.gamma.app/en/articles/11016390-introduction-to-the-gamma-dashboard)
- **Documented scope and reuse:** In Gamma 5, themes live on an individual file by default, and editing that file theme does not affect other files. Gamma says a file theme can be saved to the workspace for reuse; workspace themes can then be applied to other files. The separate theme-selection guide says choosing a preview applies and saves the selected theme. These are Gamma-documented behaviors, not persistence inferred from the screenshot. [Customize themes, colors, and fonts](https://help.gamma.app/en/articles/11029150-how-do-i-customize-themes-colors-and-fonts-in-gamma) [Change a Gamma theme](https://help.gamma.app/en/articles/10262646-how-do-i-change-my-gamma-theme)
- **User-provided brand palette:** The user supplied full 50-950 color ramps and identified the `500` tokens as the primary brand colors: VibeGroup `#0a1464`, Tergos `#311857`, Spilberg `#00c84b`, Eswelt `#00352b`, VVB `#122029`, and Altus / Perca Bordeaux `#4d0000`. The palette also includes neutral and supporting color families. This is user-provided project input, not independently verified brand guidance.

## SiNiHu implications

Treat the dashboard as the starting point for multiple creation paths: prompt-based creation, blank deck, template browsing, and returning to recent work. Keep template search and filters distinct from visual theme customization. Treat generation, editing, and presenting as distinct steps: provide a post-generation editor with slide navigation and editing tools, then a clear Present action for the audience-facing view. Make that presentation a first-class output, with explicit in-tab/full-screen entry, predictable keyboard and touch navigation, visible progress, and a distinct presenter view for private notes. Define overflow separately for the two outputs: the web presenter should allow vertical scrolling through long slide/card content, while the PPTX export preserves the intended objects and layout within the limits of PowerPoint's fixed slide canvas. Treat PPTX as a one-way deliverable: SiNiHu should produce and validate the exported file, but does not need to track or synchronize edits made later in PowerPoint. For initial visual styling, use the user's supplied brand palette and guide to define a coherent starting theme; defer a full theme marketplace or multi-brand selection workflow. Keep themes (appearance) distinct from templates (starting content and layout). If needed later, support the other supplied brand guides as selectable brand themes, with clear scope for whether a theme applies to one deck or can be reused. These are design recommendations drawn from Gamma's documented behavior, the user-provided screenshots and palette, and the SiNiHu goal of building a slide-deck application; they are not claims about Gamma internals.

# Model Default and Usage Controls

Type: grilling
Status: open
Blocked by: 05

## Question

Define how a user's personal default model is selected from their connected providers and how the app behaves when that connection or model is unavailable. Decide what provider usage information to show and which per-user limits SiNiHu can enforce reliably. The first release uses a personal default rather than project- or session-specific model overrides; do not present incomplete provider data as precise cost or quota information.

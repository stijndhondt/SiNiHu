# Local Backup and Storage Durability

Type: grilling
Status: open
Blocked by: 02, 03

## Question

Decide the first-release contract for browser storage quotas, eviction or browser-profile loss, backup reminders, and recovery of local projects. Define whether ZIP export is the only supported backup, how users discover that local data is at risk, and what recovery/import behavior is required. Base the decision on the agreed account lifecycle and versioned deck package; do not add server sync as an implicit backup.

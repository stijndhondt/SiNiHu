# AI Editing and Proposal Contract

Type: grilling
Status: open
Blocked by: 03, 06, 07

## Question

Define the user-visible behavior of Deck AI and Slide AI from instructions and context through review and application. Specify the proposal preview, how changes are mapped to the shared editable slide structures, whether users can accept or reject changes at deck/slide/content-block granularity, and how revisions are recorded. AI output must not silently overwrite manual work; preserve the agreed rollback version at AI-session start and manual Save Version action.

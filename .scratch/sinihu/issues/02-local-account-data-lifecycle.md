# Local Account Data Lifecycle

Type: grilling
Status: open
Blocked by: 01

## Question

Define how browser-local projects and reusable content behave across sign-in, account switching, sign-out, and account removal. Decide how the active account is selected and how one household member is prevented from casually opening another member's local work in a shared browser profile, given that same-origin browser storage is not a hard security boundary. Include what remains available for ZIP export and what is deleted at each lifecycle step.
